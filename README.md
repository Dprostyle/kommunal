# Communal

Cupertino Flutter app for utility bill payments (UI/UX only, mock data).

## Run

```bash
flutter pub get
flutter run
```

## Structure

- `lib/app` — CupertinoApp, theme tokens
- `lib/models` — API-friendly models
- `lib/data` — mock data + repositories (swap for real API later)
- `lib/screens` — Home / History / Profile
- `lib/widgets` — shared UI components
